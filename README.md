## How to run it

```sh
python3 main.py
```

`build_image.py` draws the 1024x1024 front page with Pillow, deterministically — run it twice and the bytes match. `main.py` needs only the standard library and copies the finished `entry.png` to `/output/entry.png`. `build.sh` runs both steps in order.
