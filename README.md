A single image summing up the world's news of Thursday 19 November 2026: GTA VI rolls out worldwide after a 13-year wait, Democrats nominate Hakeem Jeffries for House Speaker, the EU proposes a €45bn loan for Ukraine, the US and Iran trade fire again in the Gulf, Cyclone Akvan bears down on India's east coast, and Voyager 1 reaches one light-day from Earth. ## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies `entry.png` to `/output/entry.png`. `build_image.py` (Pillow) draws the image deterministically from scratch; `build.sh` runs both.
